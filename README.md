HWiNFO PERFORMANCE LAB v6.6
===========================

CARD CONTROL VISIBILITY
-----------------------
Each pinned card now has a small "..." button in its header.

Click it to hide/show the card's bottom control strip:
- Large value selector
- Graph checkbox
- 5s average checkbox

This affects only the controls. The metric, Current / Min / Avg / Max values and
graph remain exactly as configured.

GLOBAL CONTROL
--------------
Dashboard -> Card controls:
- Show all
- Hide all

The visibility is stored per pinned card and is included in Export setup / Import
setup, so the compact layout survives refreshes and can be moved to another PC.
