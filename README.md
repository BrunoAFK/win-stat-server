HWiNFO PERFORMANCE LAB v6.9.2
=============================

COMMAND BAR POLISH
------------------
- Search now consumes all available free horizontal space.
- Presets / Dashboard / Session / Settings stay compact.
- Lap navigation has moved completely to the far-right side of the command bar.
- Lap UI is now a compact rounded capsule rather than a large form-style select.
- Current lap is shown simply as "Lap N".
- "+ Lap" is integrated into the same compact control.
- On narrower windows Search wraps to its own row before the command controls.

PAGE VERSION
------------
The stale "v5" text in the page header has also been corrected.

All v6.9.1 features remain unchanged.
