HWiNFO PERFORMANCE LAB v6.8.1
=============================

TOP-BAR LAP NAVIGATION
----------------------
Lap controls have moved into the main command bar next to Search:

  Search | View: Current lap / All session / Lap N | + New lap | Presets | ...

This makes the active analysis scope visible while working and uses the space
previously occupied by the oversized search field more efficiently.

The status strip below is now informational only:
- Session duration
- Current lap duration
- Source samples
- HWiNFO polling interval
- Last source update

No lap/session behavior changed from v6.8.
